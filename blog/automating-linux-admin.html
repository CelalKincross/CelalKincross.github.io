Building a Research Computing Lab at Home

From Linux Fundamentals to Automated Backups and Ansible

January 2, 2026 | System Administration

I wanted to practice real system administration, not isolated commands or “hello world” automation. Specifically, I wanted to simulate a research computing environment where nodes have distinct roles and automation is native.

Lab Architecture

  • lab-admin: Control plane + authoritative storage (NFS server)
  • lab-compute: Researcher-facing compute node (NFS client)
  • lab-backup: Reserved for off-host backups
  • Mac workstation: Admin control node (SSH + Ansible)

Linux Foundations: Multi-User Semantics

First, I set up the user environment to simulate a collaborative research team.

sudo adduser alice
sudo adduser bob
sudo adduser carol

sudo groupadd researchers
sudo groupadd project1

sudo usermod -aG researchers alice
sudo usermod -aG researchers bob
sudo usermod -aG researchers carol

sudo usermod -aG project1 alice
sudo usermod -aG project1 bob

Shared Directory Layout

sudo mkdir -p /research/project1
sudo chown root:researchers /research
sudo chmod 2775 /research

sudo chown root:project1 /research/project1
sudo chmod 2770 /research/project1

The setgid bit ensures that new files inherit the group ownership of the directory, facilitating seamless collaboration.

Shared Storage with NFS

To share data across nodes, I implemented NFS (Network File System).

NFS Server Configuration

# /etc/exports
/research lab-compute(rw,sync,no_subtree_check)

Automation with systemd

I moved away from legacy cron jobs in favor of systemd timers for better logging and dependency management.

Health Check Script

#!/bin/bash
TARGET="/research"
LOGTAG="research-check"

if mountpoint -q "$TARGET"; then
    logger -t "$LOGTAG" "OK: $TARGET is mounted"
    exit 0
else
    logger -t "$LOGTAG" "FAIL: $TARGET is NOT mounted"
    exit 1
fi

Automated Backups

Using rsync with --link-dest, I created a snapshot-style backup system that is efficient on storage.

#!/bin/bash
set -eu
SRC="/research/"
DEST="/var/backups/research"
TODAY="$(date +%F)"
SNAPSHOT="$DEST/daily-$TODAY"
CURRENT="$DEST/current"

rsync -a --numeric-ids --delete --link-dest="$CURRENT" "$SRC" "$SNAPSHOT"
rm -f "$CURRENT"
ln -s "$SNAPSHOT" "$CURRENT"

Key Takeaways

  • systemd timers > cron for robust infrastructure.
  • Backups must be restored to be trusted.
  • Good system administration makes correct behavior boring.
