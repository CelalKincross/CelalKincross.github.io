# John Dall'Olio - Portfolio Website

This is the personal portfolio and blog for John Dall'Olio, showcasing projects in IT System Administration, Cybersecurity, and Software Development.

## Overview

- **Profile:** Professional portfolio and CV.
- **Blog:** Articles on System Administration, Zero-Day Vulnerability handling, and Supply Chain Security.
- **Projects:** Showcase of labs and development projects.

## Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Styling:** Custom minimal CSS with responsive design
- **Deployment:** GitHub Pages

## Local Development

To run the site locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/CelalKincross/CelalKincross.github.io.git
   ```
2. Open `index.html` in your browser or run a simple server:
   ```bash
   python3 -m http.server
   ```
